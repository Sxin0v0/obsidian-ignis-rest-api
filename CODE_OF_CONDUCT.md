# Code of Conduct

We want project discussions to remain technical, respectful, and useful.

Participants are expected to:

- discuss ideas and code without personal attacks;
- give actionable feedback and assume good faith;
- respect privacy and never publish another person's credentials or private
  data;
- avoid harassment, discrimination, intimidation, or deliberately disruptive
  behavior.

Maintainers may edit, hide, or remove content that violates these expectations
and may restrict participation when necessary to keep the project safe and
constructive.

For sensitive security matters, follow `SECURITY.md` rather than posting
private details publicly.
